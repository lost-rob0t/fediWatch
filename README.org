#+title: FediWatch
* FediWatch
FediWatch consumes automation targets and monitors Mastodon account/timeline APIs.
It publishes StarIntel documents through StarRouter.

** Document contract
StarLang is the sole source of truth. The complete generated 0.10.1 release is
vendored in ~schemas/starintel-0.10.1~, with immutable source commit and hashes in
~schema/starintel-schema.lock.json~. Maintained document and Router dependencies
are pinned, and the build verifies their complete release agrees with this lock.

Observed accounts produce canonical ~user~ documents. Timeline observations
produce ~socialmpost~, ~user~ and ~relation~ documents with source-defined
references and the ~org.starintel/core@1/owns~ predicate. The complete original
account/status object is retained in ~raw~, including unknown fields, HTML,
false, null and empty values. Unresolved media URLs and local reply IDs remain
in raw input rather than becoming invented document references. User and post
identity formulas retain the historical MD5 inputs; relation identity is stable
for the observed account/post pair. Each observation is validated before any
of its projections is published.

Canonical generated Target bindings are received through the maintained Router.
Set the actor to ~fediwatch~ and ~options.typ~ to ~Domain~ for a timeline or ~User~
for an account lookup. ~options.auth~ supplies the API token; ~options.ua~ can
set the timeline user agent. Tokens are passed in the HTTP authorization header.

** Build and run
#+begin_src shell
nix build
./result/bin/fediWatch --apiAddress=tcp://127.0.0.1:6001 --subAddress=tcp://127.0.0.1:6000
#+end_src

Native Nim 2 installations can use ~nimble install~ with OpenSSL and ZeroMQ.
~FEDIWATCH_LOG~ sets the log path (default ~fediWatch.log~), and
~FEDIWATCH_LOG_LEVEL~ selects a Nim log level, such as ~lvlInfo~ or ~lvlError~.
The tested Nix package carries its HTTPS trust bundle. ~SSL_CERT_FILE~ can supply
a deployment CA bundle while retaining peer certificate validation.

#+begin_src shell
docker build -t fediwatch .
docker run --init --rm --network=host fediwatch
#+end_src

The container builds the same fully tested Nix package and includes its runtime
closure. Configure broker addresses with command-line arguments for deployment.

** Validation and releases
#+begin_src shell
python3 scripts/sync-starintel-schema.py
nix flake check -L
#+end_src

The upstream check verifies the immutable StarLang release. The full Nix gate
builds the actor and tests both native and installed binaries against an actual
local broker and HTTPS Mastodon endpoint: generated target routing, account
lookup/authentication/cache, timeline production, reference integrity, stable
identity, lossless raw input, duplicate suppression and invalid observation
rejection. Production endpoints are not contacted by these checks.

Nim 2.2.12 gives the ULID dependency's ~pkg/random~ and HTTP's ~std/random~ the
same generated C filename. The Nix build renames only the pinned ULID random
module in its temporary build tree; its implementation and random algorithm
are unchanged. OpenSSL is linked explicitly for the SSL-enabled build.

Update source releases using ~scripts/sync-starintel-schema.py --commit <full-commit>~
and repin the maintained runtimes to the same release.
